# B23-O-L1 GLEIF 离线 mapper lane 验收记录

> 完成日期：2026-07-20

> 状态：纯 mapper 层已实现并继承 B23-OC；后续 B23-RA 已补离线 RA/EntityID 第二身份映射，生产仍为 `NOT_READY`

## 范围与交付

B23-O-L1 只在 `infra/external/src/test` 建立 GLEIF/LEI 离线 conformance lane：

- `GleifTransport` 固定一个精确 LEI 调用和一个 legal-name/legal-jurisdiction 单页调用，不开放 endpoint、credential、任意 filter、分页 token、Level 2、历史或 bulk surface；
- `GleifLeiRecordMapper` 把显眼合成的 JSON:API-like LEI payload 缩减为既有 `EnterpriseDataObservation`；
- `GleifEnterpriseDataSource` 只绑定一个合成 tenant 和受治理辖区；B23-RA 后其 capability 声明 LEI 与可输出的 Companies House identity type，但仍不含 Spring stereotype 或 runtime registration；
- `GleifEnterpriseDataContractTest` 继承 `OfficialSourceEnterpriseDataContract`，并补充 GLEIF 资格、状态、RA 失败关闭、单调用和 tenant 负向用例。

本轮没有修改 `src/main`、`conf`、组合根、公共 API、domain identity catalog 或生产 policy。它不是 HTTP adapter，也不提供 readiness snapshot、共享 admission、真实来源权利证据或 live conformance。

## Mapper 结论

- 只有 `GENERAL`、`FUND`、`BRANCH`、`RESIDENT_GOVERNMENT_ENTITY` 和 `INTERNATIONAL_ORGANIZATION` 通过组织资格；exact 对 `SOLE_PROPRIETOR`、缺失或未知 category 返回稳定 `UNSUPPORTED`，search 在值离开 mapper 前静默丢弃这些候选。
- `EntityStatus` 只映射主体 `ACTIVE/INACTIVE/UNKNOWN`；`RegistrationStatus` 独立映射 `CURRENT/STALE/TRANSITIONING/SUPERSEDED/INVALID/RETIRED/UNKNOWN`。
- LEI 继续由既有 `RegisteredIdentifierCatalog` 完整校验。响应 identity 不一致收敛为 `UNAVAILABLE`。
- 本批次当时抑制 `RA000585` 和 `RegistrationAuthorityEntityID`；后续 [B23-RA](B23-RA.md) 已在 test scope 中以既有 `UK_COMPANIES_HOUSE/GB_CH_NUMBER` 补齐三条 RA 的第二身份映射。
- `EntityCreationDate` 以 `ESTABLISHED` 输出；`Registration.LastUpdateDate` 只进入 `sourceUpdatedAt`，`NextRenewalDate` 不成为 revision、expiry 或 standing 的替代输入。
- 只映射 legal name、legal jurisdiction、legal address 和既有 allowlist。LOU、provider locator、关系、人员和未来额外字段 canary 均在 mapper 边界丢弃，native shape 与异常的字符串输出保持 redacted。

## Transport 与失败边界

- capability 不调用 transport；每次 exact/search 最多调用 stub transport 一次，无 retry 或 fallback；
- search transport 只收到裁剪后的名称、受治理 legal jurisdiction 和调用方 1..20 limit；
- 空 exact 与空 search 分别成为 `Optional.empty()` 和空列表；
- quota、unsupported、transport failure、malformed envelope、schema/identity mismatch 只暴露 `LIMITED`、`UNSUPPORTED` 或 `UNAVAILABLE`；任意 runtime/provider 文本不会成为公开异常消息或 cause；
- cross-tenant 调用在 transport 前失败关闭。

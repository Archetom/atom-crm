# B26a 验收记录：统一调度与公海自动收回

## 已实现范围

- `V65__create_automation_scheduler.sql` 建立 tenant/kind schedule、唯一 occurrence run、非终态 active-slot、claim/retention 索引，并回填当前启用的 Customer/Contact 自动收回配置；`V66__add_automation_cadence_control.sql` 增加全局单行的单调 cadence revision control。
- `AutomationRunPump` 以 MySQL UTC materialize、claim 和递增 lease fence；claim 会先原子终结超出 deadline/max-attempts 的 occurrence，业务处理、`SUCCEEDED` terminal state 与 affected count 在同一 `CommandServiceTemplate` 事务中提交。失败只复用同一 run，使用固定安全原因进入有界 `RETRY_WAIT` 或 `DEAD`，过期 owner 不能再写 recovery。
- Customer/Contact handler 在各自 customization guard 后验证 schedule/run fence，继续复用独立 cursor、pool/record 上限和仓储，不合成 caller；candidate cutoff 使用 run 的稳定 evaluation time，membership entered time 使用 fence 验证后的数据库 UTC。
- 会影响自动收回派生状态的公海创建、更新、状态变更和删除按 object guard → schedule → pool root 同步；暂停、重启或 cadence revision 变化取消旧 non-terminal run 并增加 generation。启用且合法的副本在启动时锁定全局 revision；升级会对账所有 schedule、取消旧 run，而较旧副本只能 `NOT_READY`，不能回滚 revision 或 claim。
- `BackgroundWorkScheduler` 是唯一 `@EnableScheduling` composition-root pulse。automation 与 attachment 使用独立、有界 local lane；附件每次仍只调用其既有 worker 的 `runOnce()`，不写 automation run。
- `automationScheduling` Actuator health contributor 在 enabled+invalid、未对账或 revision 漂移时报告 `DOWN/NOT_READY`；代码为所有时长和并发参数设有绝对上限及 deadline/lease/backoff 关系校验。安全 metrics 覆盖每 kind 的 materialized/claimed/succeeded/retry/dead/cancelled、due lag、affected、run/schedule state 和最近成功 UTC，以及每 lane 的 active/queued/pulse/duration/recent success；标签只使用固定 lane/kind/outcome/status。后台命令模板使用安全日志策略，不输出异常 class/message。B24 conformance manifest 已跟随统一 scheduler 重命名。

## 非目标

没有 public automation API、租户 cron/时区、脚本、工作任务重复、通知、公告定时发布或外部副作用投递。`atom.scheduling.enabled` 默认 `false`；非法调度参数不阻止正常 CRM 请求。

## 验证

- `AutomationRunPumpTest` 覆盖 closed handler catalog、成功结算、同 occurrence 恢复与安全后台日志。
- `AutomationSchedulerIntegrationTest`（`CI=true`）覆盖 V65 首次激活、schedule/run materialize、claim、fence、terminal settlement、pause/restart generation、超限/过期 DEAD、stale recovery fence、active-run starvation 和 V1→V2 全局 revision 对账/旧副本拒绝。
- Customer/Contact Docker 集成用例同时断言自动收回配置会派生各自的活动 schedule。

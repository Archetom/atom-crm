# B29b 验收记录：MarketingForm 匿名 FILE 草稿与原子 Lead 绑定

## 实现范围

- 活动 MarketingForm 可以配置当前 active 的 custom LEAD `FILE` 字段；public rendering 只暴露已配置字段，标量 `values` 永远拒绝 FILE ID。
- `POST /api/v1/open/marketing-forms/{publicId}/file-drafts` 只返回一次随机 256-bit credential。数据库只保存 purpose-separated SHA-256 digest，并将 credential 精确绑定 tenant、form、form version 与 draft；它不是 `AuthenticatedCaller`、member、tenant bearer 或下载令牌。
- 公开候选创建、内容上传、受控状态、撤回和提交都要求 canonical publicId、exact draftId 和 `Authorization: MarketingFileDraft <credential>`。无凭据、跨 form/version/draft 或失效草稿统一失败关闭；公开状态没有 scanner reason、locator、checksum、tenant、owner、Lead 或下载内容。
- `V78__create_marketing_file_draft_and_upload_origin.sql` 建立 draft/candidate/capacity-guard 表，并将 `crm_attachment_file` 归因扩展为 exact-one `MEMBER` 或 `PUBLIC_MARKETING_FORM`。匿名候选的 `uploader_actor_id` 始终为空，origin 指向 exact draft；candidate 的 `(tenant_id,draft_id,file_id)` 复合外键强制它只能引用同一个 exact draft 的 public-origin file。
- 每 draft 最多十个候选，expected/reserved 和 actual bytes 都由 32 MiB deployment cap 约束；每 form 最多 100 个 active drafts 由 MySQL guard 仲裁。新 draft/candidate 还要求 B24 runtime、storage 和 inspection readiness 与独立 `atom.files.public-marketing.*` gate。upload intent 与首次 retention schedule 都不晚于 exact draft deadline。
- 带 FILE 的 public submission 在同一命令事务内锁 form、LEAD customization guard、draft/candidates，创建 Lead、发布/绑定 exact READY set、消费 draft，并追加 B19 attribution。任一失败回滚 Lead、binding、draft state 与 attribution。
- `publicMarketingFile` health 只返回固定状态 `DISABLED`、`CONFIG_INVALID`、`FILES_NOT_READY`、`RUNTIME_FAILURE`、`READY`；`atom.public_marketing_file.lane_state` 只使用固定 `lane=public_marketing_file` 与该 `state` 标签，不包含 tenant、form、draft、file、source 或异常内容。

## 自动化证据

- `MarketingFormSubmissionRateLimiterTest`：canonical direct/alias public route admission，含 public FILE route kind。
- `PublicMarketingFileHealthIndicatorTest`：disabled、invalid、not-ready、runtime failure 与 adapter success 才恢复 ready 的固定健康状态。
- `MarketingFileDraftServiceImplTest`：intent/retention 时间永不超过 draft deadline。
- `sh ./mvnw -q -pl infra/rest -am test`
- `CI=true sh ./mvnw test`：Flyway V78、匿名 origin/candidate、上传/检查/消费与同事务 Lead binding 的 MySQL gate。

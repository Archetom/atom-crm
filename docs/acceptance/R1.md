## 自动门禁

统一入口：

```bash
make release-verify
```

等价的核心构建命令：

```bash
CI=true sh ./mvnw --batch-mode --no-transfer-progress clean install
```

该门禁验证：

- Maven reactor、运行时 API 元数据、README 和 OpenAPI 测试均声明 `1.0.0`；
- 发布面不存在 `-SNAPSHOT` 版本，内部 reactor 依赖统一使用 `${project.version}`；
- Maven Enforcer 的 Java、Maven 和依赖收敛规则通过；
- ArchUnit、领域、应用、REST、持久化转换和安全边界测试通过；
- MySQL Testcontainers 执行空库 `V1..V85`、历史迁移、tenant 隔离、锁序、
  乐观锁、唯一仲裁、事务回滚和 HTTP 契约回归；
- `OpenApiIntegrationTest` 对外发布 `info.version=1.0.0`；
- 全模块完成 `clean install`，不是仅编译或跳过测试的构件。

# B28b 验收记录：OA 公告到可靠 EMAIL delivery

## 实现范围

- `V76__add_oa_announcement_notification_delivery.sql` 将现有 delivery backfill 为 `WORK_TASK_NOTIFICATION`，并以 exact-one CHECK、Work composite FK 与 OA recipient composite FK 约束两种闭合 source。
- `oaAnnouncementEmailEnabled` 独立于 Work `emailEnabled`，缺失记录和旧 PUT 的省略字段均保持 OA 为 OFF。
- 发布协调器在公告根、recipient snapshot 与可投递 OA EMAIL outbox 同一事务中提交；只选择当前 active、具有 `notifications:read` 与 `oa-announcements:read` 且已 opt-in 的 snapshot recipient。
- application admission registry 穷尽地路由 Work task-first 或 OA announcement → recipient → delivery；OA command 只有固定 template、公告 ID、标题和实际发布时间，不含 body、selector、recipient list 或 endpoint ledger。
- withdraw/delete 将未跨 dispatch boundary 的 OA row 结算为 `SUPPRESSED/ANNOUNCEMENT_WITHDRAWN`，有 dispatch history 的 row 结算为 `AMBIGUOUS`；不改变 OA recipient 或 read receipt。
